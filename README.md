# Markdown to HTML Converter

A lightweight browser-based Markdown to HTML converter built with vanilla JavaScript. It converts Markdown as you type and displays both the generated HTML and a live preview.

## Features

- Live Markdown conversion
- Live rendered preview
- Generated HTML output
- Headings (`#` to `######`)
- Bold and italic text
- Links
- Images
- Blockquotes

## Technologies

- HTML
- CSS
- JavaScript
- Regular Expressions

## Example

```markdown
# Welcome

This is **bold** and this is *italic*.

> Markdown is easy to read and write.
